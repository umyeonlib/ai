# 연암도서관 · 나의 AI 활용도, 다음 책

처음 화면의 **AI 맞춤도서 추천받기**를 누르면 같은 페이지에서 1~5번 문항이 펼쳐집니다. 관심 분야·코딩 경험·AI 활용 상황을 바탕으로 연암도서관의 실제 소장도서 3권을 바로 아래에 추천합니다.

공개 사이트: https://umyeonlib.github.io/ai/yeonam/

이 주소의 사이트는 ChatGPT 구독·로그인·API와 독립적으로 GitHub에서 운영됩니다. ChatGPT 구독을 해지해도 GitHub 계정과 공개 저장소·Pages 게시 상태를 유지하면 계속 이용할 수 있습니다. `chatgpt.site` 주소는 이 GitHub 본사이트로 이동시키는 안내 페이지만 제공합니다. QR은 중간 안내 없이 GitHub 본사이트로 직접 연결됩니다.

## 무료 운영

- 공개 GitHub 저장소의 GitHub Pages 기본 주소를 사용합니다.
- AI API, 유료 서버, 데이터베이스, 도메인 구매, 구독형 QR 서비스를 사용하지 않습니다.
- `index.html` 하나로 작동합니다. 외부 스크립트·폰트·이미지·AI 서비스에 의존하지 않습니다.
- 등록·접수·자동 결제 기능이 없으며, 별도 결제 수단을 등록할 필요가 없습니다.
- 2026년 10월 20일 확인 기준 GitHub Free의 공개 저장소는 Pages를 무료로 이용할 수 있습니다. 외부 서비스의 장래 정책까지 보장할 수는 없습니다.
- GitHub Pages 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- 용량·트래픽 등 이용 한도: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## 이용 흐름

1. QR 또는 공개 주소로 로그인·회원가입 없이 접속합니다.
2. **AI 맞춤도서 추천받기**를 누릅니다.
3. 같은 페이지에서 5문항이 한꺼번에 펼쳐집니다. 별도 사전 질문이나 다음 문항 페이지가 없습니다.
4. 1번 관심 분야, 2번 코딩 경험, 3~5번 활용 상황에 답합니다.
5. **나에게 맞는 도서 추천 보기**를 누르면 같은 페이지 아래에 결과와 추천도서 3권이 나옵니다.
6. 도서명·저자·청구기호·코너 위치를 보고 서가에서 찾습니다.

답변을 바꾸면 이전 추천은 숨겨지고, 다시 추천 보기 버튼을 눌러 새 답변을 반영합니다. 추천 목록은 텍스트 파일 또는 인쇄/PDF로 저장할 수 있습니다. 전체 소장도서는 별도 도서 검색 메뉴로 찾아볼 수 있습니다.

- 원본의 연속 공백과 저자·출판사 뒤의 서지 구두점만 표시용으로 정리했습니다.
- 목록에 오래된 프로그래밍 서적도 포함되어 있어, 맞춤 추천에는 71종을 별도로 선정하고 관심 분야·단계·코딩 경험을 적용합니다. 전체 476종은 검색할 수 있습니다.
- 서명과 주제에 근거한 추천입니다. 책의 전체 본문을 분석한 추천이 아닙니다.
- 실시간 대출 현황과 연결되어 있지 않습니다.

## 진단 기준과 개인정보

관심 분야와 코딩 경험은 추천 주제와 기술 난이도에 반영하며 점수에는 포함하지 않습니다. 활용 상황 3문항은 각각 0~2점이며 합계 6점을 100점으로 환산합니다. 0~24점 첫걸음, 25~49점 탐색, 50~74점 활용, 75~100점 확장 단계로 안내합니다. 이 기준은 독서 안내를 위한 자체 학습용 기준입니다. 표준화된 능력 인증이나 실제 AI 도구 조작 시험이 아닙니다.

학번·이름·연락처를 받지 않습니다. 선택과 결과는 브라우저 메모리에서만 처리하며 외부로 전송하거나 저장하지 않습니다. 새로고침하면 초기화됩니다. 운영자는 개인별 결과나 방문 통계를 수집하지 않습니다. 호스팅 제공자는 일반적인 접속 기록을 처리할 수 있습니다.

## 담당자 운영

- 포스터 QR: 홈페이지 상단 **QR 공유 → QR 내려받기**. SVG 파일을 내려받습니다. 별도 제공된 PNG 파일도 사용할 수 있습니다.
- QR은 공개 주소를 직접 담습니다. QR 서비스의 구독이나 갱신이 필요하지 않습니다.
- GitHub 계정·저장소 이름이나 `yeonam/` 경로를 바꾸면 기존 QR의 목적지가 달라지므로 주소를 유지하세요.
- 이 사이트는 기존 `ai/` 페이지 아래 `yeonam/`에 추가된 별도 페이지입니다.
- 도서를 추가·변경할 때는 새 엑셀 목록과 이 페이지 주소를 함께 전달해 갱신할 수 있습니다.
- 개발자가 직접 수정하려면 `index.html` 안의 `catalog-data` JSON을 바꾸고 메타데이터·홈페이지 기준일·선정 도서를 함께 검토해야 합니다. 소장 목록 JSON만 별도 파일로 바꾸어도 자동 갱신되지는 않습니다.

## 무료 운영 조건 점검

추가 운영비 없이 제공한다는 조건을 확인하는 자동 점검을 1시간 간격으로 등록했습니다. GitHub 본사이트의 현재 구성에 적용되는 유료화가 공식 확인되면 해당 실행에서 연암도서관 전용 `yeonam/` 게시 경로를 중지하도록 지시되어 있습니다. ChatGPT Sites 안내 페이지에만 요금이 생기는 경우 안내 페이지만 중지하고, 무료로 유지되는 GitHub 본사이트는 계속 제공합니다. ChatGPT 구독 상태나 안내 페이지 중단을 이유로 GitHub 본사이트를 중지하지 않습니다. 다른 페이지와 계정 전체의 결제 설정은 변경하지 않습니다.

이 기능은 자동화가 실행되고 연결·권한이 유지되는 동안 공식 정책을 정기 확인하는 작업입니다. 외부 서비스의 요금 전환 시각에 정확히 맞춘 실시간 차단이나 호스팅 사업자가 강제하는 0원 결제 한도는 아닙니다. 점검 및 게시 반영 시간이 걸릴 수 있습니다. ChatGPT 자동 점검은 GitHub 사이트 자체와 별개 기능이며, ChatGPT 구독 해지 이후에도 점검 작업이 계속 실행된다고 보장하지 않습니다. 무료 상태를 확인할 수 없거나 실제 중지에 실패하면 사용자에게 알리도록 설정했습니다.

## 재생성 가능한 소스

제작 프로젝트는 `index.template.html`, `style.css`, `app.js`, `build_catalog.py`, `catalog-source.json`으로 구성됩니다. `build_catalog.py`는 원본 XLS를 읽어 데이터와 QR을 넣은 GitHub 게시용 `dist/index.html`과 ChatGPT 주소 이동용 `out/index.html`을 생성합니다. 두 파일은 별도 빌드 없이 열립니다. `.openai/hosting.json`은 이동용 `out`만 게시합니다.

검증: 734건 원본 대조, 답변 486가지 조합에 따른 추천·점수 계산, 5문항 펼치기, 같은 페이지 결과 표시, 답변 수정 시 이전 결과 숨김, 검색·이스케이프·외부 호출 부재와 GitHub 이동 페이지를 확인했습니다. 실제 브라우저 화면 검증은 제작 환경 제약으로 수행하지 못했습니다.
