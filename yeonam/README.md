# 연암도서관 · 나의 AI 활용도, 다음 책

이용자가 관심 분야와 코딩 경험을 선택하고 상황형 12문항에 답하면, 연암도서관 3층 AI 코너의 실제 소장도서를 추천합니다.

공개 사이트: https://umyeonlib.github.io/ai/yeonam/

## 무료 운영

- 공개 GitHub 저장소의 GitHub Pages 기본 주소를 사용합니다.
- AI API, 유료 서버, 데이터베이스, 도메인 구매, 구독형 QR 서비스를 사용하지 않습니다.
- `index.html` 하나로 작동합니다. 외부 스크립트·폰트·이미지·AI 서비스에 의존하지 않습니다.
- 등록·접수·자동 결제 기능이 없으며, 별도 결제 수단을 등록할 필요가 없습니다.
- 2026년 10월 20일 확인 기준 GitHub Free의 공개 저장소는 Pages를 무료로 이용할 수 있습니다. 외부 서비스의 장래 정책까지 보장할 수는 없습니다.
- GitHub Pages 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- 용량·트래픽 등 이용 한도: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## 이용 흐름

1. QR 또는 공개 주소로 접속합니다.
2. 관심 분야 한 가지와 코딩 경험을 선택합니다.
3. 프롬프트 설계·정보 검증·안전한 활용·작업 설계 각 3문항에 답합니다.
4. 진단 단계, 영역별 점수, 해설, 연습용 미션과 도서 추천을 확인합니다.
5. 책의 도서명·저자·청구기호·코너 위치를 확인해 서가에서 찾습니다.

추천 목록은 텍스트 파일로 내려받거나 인쇄/PDF로 저장할 수 있습니다. 전체 도서 목록에서 제목·저자·청구기호·등록번호를 검색하고 코너와 주제를 선택할 수 있습니다.

## 도서 데이터

- 원본: `3층 AI신간도서코너.xls` / `서AI도서코너 도.xls`
- 목록 기준일: 2026-10-20
- 신간 코너 174권, AI도서 코너 560권, 총 734권
- 같은 서명·저자·발행연도를 묶은 476종
- 코너 이름: `3층 AI신간도서코너`, `3층 AI도서 코너`
- 복본의 등록번호·청구기호와 권차·코너 정보는 각각 보존합니다.
- 원본의 연속 공백과 저자·출판사 뒤의 서지 구두점만 표시용으로 정리했습니다.
- 목록에 오래된 프로그래밍 서적도 포함되어 있어, 맞춤 추천에는 71종을 별도로 선정하고 관심 분야·단계·코딩 경험을 적용합니다. 전체 476종은 검색할 수 있습니다.
- 서명과 주제에 근거한 추천입니다. 책의 전체 본문을 분석한 추천이 아닙니다.
- 실시간 대출 현황과 연결되어 있지 않습니다.

## 진단 기준과 개인정보

각 문항은 0~3점이며 합계 36점을 100점으로 환산합니다. 0~24점 첫걸음, 25~49점 탐색, 50~74점 활용, 75~100점 확장 단계로 안내합니다. 이 기준은 독서 안내를 위한 자체 학습용 기준입니다. 표준화된 능력 인증이나 실제 AI 도구 조작 시험이 아닙니다.

학번·이름·연락처를 받지 않습니다. 선택과 결과는 브라우저 메모리에서만 처리하며 외부로 전송하거나 저장하지 않습니다. 새로고침하면 초기화됩니다. 운영자는 개인별 결과나 방문 통계를 수집하지 않습니다. 호스팅 제공자는 일반적인 접속 기록을 처리할 수 있습니다.

## 담당자 운영

- 포스터 QR: 홈페이지 상단 **QR 공유 → QR 내려받기**. SVG 파일을 내려받습니다. 별도 제공된 PNG 파일도 사용할 수 있습니다.
- QR은 공개 주소를 직접 담습니다. QR 서비스의 구독이나 갱신이 필요하지 않습니다.
- GitHub 계정·저장소 이름이나 `yeonam/` 경로를 바꾸면 기존 QR의 목적지가 달라지므로 주소를 유지하세요.
- 이 사이트는 기존 `ai/` 페이지 아래 `yeonam/`에 추가된 별도 페이지입니다.
- 도서를 추가·변경할 때는 새 엑셀 목록과 이 페이지 주소를 함께 전달해 갱신할 수 있습니다.
- 개발자가 직접 수정하려면 `index.html` 안의 `catalog-data` JSON을 바꾸고 메타데이터·홈페이지 기준일·선정 도서를 함께 검토해야 합니다. 소장 목록 JSON만 별도 파일로 바꾸어도 자동 갱신되지는 않습니다.

## 재생성 가능한 소스

제작 프로젝트는 `index.template.html`, `style.css`, `app.js`, `build_catalog.py`, `catalog-source.json`으로 구성됩니다. `build_catalog.py`는 원본 XLS를 읽어 데이터와 QR을 넣은 `dist/index.html`을 생성합니다. 게시 파일 자체는 별도 빌드 없이 열립니다.

검증: 734건 원본 대조, 관심·코딩·진단 단계 72가지 추천 조합, 점수 경계값, 12문항 이동, 검색·이스케이프·외부 호출 부재를 확인했습니다. 실제 브라우저 화면 검증은 제작 환경 제약으로 수행하지 못했습니다.
